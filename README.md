# Crypto Tycoon — своя криптомонета

## Файлы в этой папке (загружайте ВСЕ):
- index.html — сама игра
- manifest.json — описание приложения
- sw.js — офлайн-режим
- icon-192.png и icon-512.png — иконки

## Веб версия игры:
- https://hiy8886566-dev.github.io/Crypto-coiner/

## Установка как приложение
- Android (Chrome): меню → «Добавить на главный экран» или кнопка 📲 в игре.
- iPhone (Safari): Поделиться → «На экран „Домой"».
